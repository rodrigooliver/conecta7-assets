# Conecta7 Assets

Repositório público de assets para o aplicativo Conecta7.

## 📦 Conteúdo

Este repositório contém:
- **Bíblias**: Versões em português (ACF, ARC, NVI, RA)
- **Livros**: Livros adventistas para leitura offline
- **Hinário**: Hinário Adventista do Sétimo Dia com letras e áudios
- **Imagens**: Capas de livros e ícones

## 🔗 Como Usar

Os arquivos estão disponíveis publicamente através do GitHub Raw:
```
https://raw.githubusercontent.com/rodrigooliver/conecta7-assets/main/CAMINHO/ARQUIVO
```

## 📁 Estrutura

```
conecta7-assets/
├── bibles/
│   ├── versions/        # Arquivos JSON das Bíblias
│   └── catalog.json     # Catálogo de versões disponíveis
├── books/
│   ├── ellen-white/     # Livros de Ellen G. White
│   └── catalog.json     # Catálogo de livros
├── hymns/
│   ├── hinario-adventista/
│   │   ├── hymns.json   # Letras dos hinos
│   │   └── audio/       # Áudios MP3 dos hinos
│   └── catalog.json     # Catálogo de hinários
└── images/
    └── covers/          # Capas de livros
```

## 📊 Tamanho dos Arquivos

- ACF: ~4.2 MB
- ARC: ~4.1 MB
- NVI: ~4.0 MB
- RA: ~4.15 MB

## 🔐 Direitos Autorais

As versões da Bíblia são de domínio público ou têm permissão de distribuição.
Para livros e áudios, certifique-se de ter as permissões necessárias.
